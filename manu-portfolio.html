Selected work

Argus — large-scale async LLM ingestion

An asyncio/aiohttp backend that crawls and extracts across arXiv, Hugging Face, YC and Greenhouse/Lever/Ashby, designed to reach 500,000+ records unattended. Decoupled discovery and extraction queues keep memory flat under load; a three-tier LLM fallback chain (Gemini Flash → Groq GPT-OSS 120B → DeepSeek) with token-bucket limiting and full-jitter backoff escalates on its own so no failure class needs a human. Deduplication is atomic and idempotent via canonical URL fingerprinting plus a two-phase freshness gate, guaranteeing exactly-once processing across concurrent workers. Outputs land as a knowledge graph — PostgreSQL as system of record, projected into Neo4j edges and pgvector embeddings for multi-hop queries.

asyncio · aiohttp · PostgreSQL · Neo4j · pgvector · 21 unit tests under GitHub Actions CI

Multimodal RAG for chest X-ray reporting

A retrieval-augmented diagnostic pipeline: BiomedCLIP encodes the X-ray, a FAISS index grounds findings against retrieved reference cases, and pathologies are detected and localized before a structured report is generated. Flan-T5-Base, LoRA fine-tuned, reaches BLEU-4 of 30.70%. Deployed via Gradio with confidence scoring.

BiomedCLIP · FAISS · LoRA · Flan-T5 · Gradio

Research

Explanation-conditioned retrieval for multi-disease clinical severity

IEEE, co-author — with Kshitij S. Gharat and Dr. Gitanjali Jayaraman, VIT

  • A seven-layer clinical decision-support architecture that reuses signed SHAP attribution vectors as retrieval queries, replacing narrative-conditioned RAG with attribution-conditioned RAG across diabetes, heart disease and pneumonia models.
  • A four-method model contract admitting heterogeneous estimators — XGBoost with TreeSHAP alongside rule-based scoring — behind a single router with explicit HTTP 422 abstention for out-of-domain cases.
  • Quantified paraphrase invariance of attribution-conditioned queries (Jaccard 1.000 against 0.115 for narrative conditioning) and the TreeSHAP latency cost at 69–78× the underlying prediction, showing batching cuts per-patient attribution cost by 136×.
